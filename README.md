# Blog Portfolio (React + Express + MongoDB + Firebase)

blog-portfolio/
  backend/   Express API + MongoDB + Firebase Admin   (port 5000)
  frontend/  React (Vite) website                     (port 5173)

## Run
Terminal 1:
  cd backend
  copy .env.example .env      (Mac/Linux: cp)
  npm install
  npm run dev
  npm run seed                (once, adds 3 sample posts)

Terminal 2:
  cd frontend
  copy .env.example .env
  npm install
  npm run dev

Open http://localhost:5173
